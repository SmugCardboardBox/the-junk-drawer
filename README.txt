THE JUNK DRAWER
===============

How to run it:
1. Unzip the folder.
2. Double-click index.html.
3. It should open in your normal web browser.

Files:
- index.html  = the page structure/content
- style.css   = all styling
- script.js   = small interactive bits
- projects/eldara-trainer.html = Eldara Trainer project page

No server, framework, Node.js, or installation is required.

Note:
The page uses Google Fonts when an internet connection is available.
If you're offline, it falls back to standard system fonts.
